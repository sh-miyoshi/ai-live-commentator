# AI Live Commentator

OllamaとElectronを使って作成しているデスクトップアプリです。
AIが配信のコメントを生成してくれます。

## 使い方

1. Ollamaをインストールします
    - https://ollama.com/download
2. git cloneします
    - `git clone https://github.com/sh-miyoshi/ai-live-commentator.git`
3. npmコマンドで実行します

    ```bash
    cd ai-live-commentator
    npm install
    npm run build
    npm run dev
    ```
